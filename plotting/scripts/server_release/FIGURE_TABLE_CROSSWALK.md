## Build order

```bash
# main-text figures 2--7 (Figures 1 and 8 are preserved assets / table-derived)
python plotting/scripts/rebuild_main_figures.py

# E-Companion figures (EC.1--EC.7)
cd plotting/scripts/server_release && python build_all_figures.py

# full pipeline from locked evidence (requires l01--l31)
cd plotting/scripts/server_release && python build_derived_data.py
```

The PNGs in `plotting/figures/` are the manuscript's final unified layout.  The
plotting scripts regenerate the same data with the repository's Matplotlib
style; minor layout differences are expected.
